# GRAPE2Play 2.8.0 Standard — Release notes (bản nháp, CHƯA build)

## Thay đổi
- Hẹn giờ ngủ: bỏ Fade Out; dừng nhạc trực tiếp khi hết giờ/hết bài; không đụng âm lượng, EQ, DSP.
- Thư viện nhanh và an toàn hơn: chỉ đọc lại file đã đổi; cache có bản sao lưu; không mất bài khi USB rút/NAS lỗi/quét bị dừng.
- Thẻ nhạc: năm, số đĩa, nghệ sĩ album, nhà soạn nhạc (khi file có).
- Tìm kiếm: thêm thể loại, nghệ sĩ album, năm.
- Yêu thích, Gần đây, thống kê nghe tự đi theo khi file được di chuyển/đổi tên (khi khớp chắc chắn).

## Lưu ý khi cập nhật từ 2.7.3
- Dữ liệu giữ nguyên (cùng applicationId, versionCode 84 > 83). Lần quét đầu sẽ đọc lại thẻ nên lâu hơn.

## Chưa có / bị chặn
- Shazam: không đưa vào 2.8.0 (quyết định của chủ dự án).
- Ghi artwork/tag vào file: chưa có (app chưa ghi tag); ảnh bìa web chỉ hiển thị và có thể tắt trong cài đặt.
- Không thêm giao diện sắp xếp/lọc mới (giữ giao diện hiện tại).
- Chưa kiểm thử thực tế trên thiết bị.
